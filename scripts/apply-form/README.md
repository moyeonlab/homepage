# 지원서 구글 폼 — 만들고 홈페이지에 연결하기

## 지금 상태

- 폼을 만드는 코드는 **`Code.gs`** 가 정본이다.
- 그 코드를 모연 계정(`moyeonlabs@gmail.com`)의 Apps Script 프로젝트에 **이미 올려 뒀다.**
  - 편집기: <https://script.google.com/d/1HKjwK3dtKRR6GQojD-pakofDPQ1H3dsj5KZRIF1zokPizhNv4X9YbA9U/edit>
- **아직 실행 전이라 폼은 없다.** 아래 3단계를 한 번만 하면 된다.

## 한 번만 하면 되는 것

1. 위 편집기 링크를 **모연 계정(`moyeonlabs@gmail.com`)으로 로그인한 상태**에서 연다.
   ⚠ 다른 구글 계정으로 열면 「액세스 권한 필요」가 뜬다 — 계정 전환이 먼저다.
2. 위쪽 함수 목록에서 **`폼만들기`** 를 고르고 **▶ 실행**.
   - 처음 한 번은 권한 승인 창이 뜬다 → 모연 계정 선택 → 「고급」 → 「…(안전하지 않음)으로 이동」 → 허용.
   - 이 승인은 **사람이 클릭해야만** 된다. 구글이 새 권한을 API로 대신 주지 않기 때문에
     여기까지는 자동화할 수 없다.
3. 아래쪽 **실행 로그**에 주소 네 개가 찍힌다. 그중 **「지원서 주소」**를 복사해 온다.

## 그다음 (Claude 가 함)

받은 주소를 `content/recruitment.ts` 의 `applicationUrl` 에 넣으면
`/join` 페이지에 **「지원서 작성하기」 버튼**이 나타난다. 지금은 그 값이 비어 있어
버튼 대신 이메일 안내가 나간다.

## 문항을 고치고 싶을 때

**폼을 손으로 고치지 말 것.** 고치면 이 코드와 실물이 갈라지고, 다음 학기에
「왜 이 문항이 있는지」를 아무도 모르게 된다.

1. `Code.gs` 의 문항을 고친다
2. 편집기에 다시 올린다 (또는 편집기에서 직접 붙여넣기)
3. **`폼고치기('<폼ID>')`** 를 실행한다 — 문항만 갈아끼우고 **응답은 그대로 둔다**
   - `폼만들기` 를 다시 돌리면 **폼이 하나 더 생겨** 응답이 두 군데로 갈린다
