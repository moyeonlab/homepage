# 모두의 문제 연구소 — 홈페이지

한양대 ERICA 수리데이터사이언스학과 공식 학회 "모두의 문제 연구소" 홈페이지.
정적 사이트(HTML/CSS/JS)로, 내용은 **데이터 파일만 수정**하면 반영됩니다.

## 내용 수정 방법 (코드 몰라도 됨)

| 수정할 것 | 파일 | 방법 |
|---|---|---|
| **소식** (스터디·발표·모집·행사) | `js/news-data.js` | 배열 맨 앞에 객체 추가 |
| 프로젝트 | `js/projects-data.js` | 배열에 객체 추가 |
| 연구원 | `js/members-data.js` | 배열에 객체 추가 |

파일 상단 주석에 필드 설명이 있습니다. 수정 → 커밋 → 푸시하면 GitHub Pages가 자동 배포합니다.

## 소식 → 학과 유튜브 쇼츠 자동 연동

`js/news-data.js`에 소식을 올리면, 학과 홍보 쇼츠 파이프라인(shorts-studio)이
**저장소 커밋을 감지해 자동으로 읽어가** 쇼츠 소재 후보로 만듭니다.
별도 요청 없이 소식만 잘 올리면 됩니다. (영상화 여부는 검수 후 결정)

- 사진이 있는 소식은 `image` 필드를 채우면 쇼츠 배경으로도 활용됩니다.
- 사진은 `images/news/` 폴더에 넣고 `"./images/news/파일명.jpg"`로 참조하세요.
